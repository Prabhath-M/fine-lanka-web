# Full Sri Lanka Route Audit Sources

## RDA National Highways — Gazetted List
URL: https://rda.gov.lk/index.php?Itemid=123&id=24&lang=en&option=com_content&view=article

The Sri Lanka Road Development Authority page lists national highways by class and identifies the principal corridors used in this audit. It reports Class A roads (AA/AB/AC) and Class B roads, with the national network totals shown on the page. Relevant Class AA corridors include: AA001 Colombo–Kandy; AA002 Colombo–Galle–Hambantota–Wellawaya; AA003 Peliyagoda–Puttalam; AA004 Colombo–Ratnapura–Wellawaya–Batticaloa; AA005 Peradeniya–Badulla–Chenkaladi; AA006 Ambepussa–Kurunegala–Trincomalee; AA007 Avissawella–Hatton–Nuwara Eliya; AA009 Kandy–Jaffna; AA010 Katugastota–Kurunegala–Puttalam; AA011 Maradankadawela–Habarana–Tirikkondiadimadu; AA012 Puttalam–Trincomalee; AA014 Medawachchiya–Mannar–Talaimannar; AA015 Batticaloa–Tirikkondiadimadu–Trincomalee; AA016 Beragala–Hali-Ela; AA020 Anuradhapura–Rambewa; AA026 Kandy–Mahiyangana–Padiyatalawa; AA028 Padeniya–Anuradhapura; AA029 Vavuniya–Horowpotana; AA032 Navakkuli–Kerativu–Mannar; and AA044 Mahiyangana–Dimbulagala–Dalukkane.

Relevant local/access references on the same page include B027 approach roads to railway stations, B028 approach road to Wilpattu Sanctuary, B064 Bowatenna access road, B071 Carolina–Norton–Wanarajah, B097 Demodera–Spring Valley–Badulla, B122 Habarana–Polonnaruwa, and other B-class local roads. The page distinguishes Class A/B national corridors from smaller roads and access routes.

## RDA Interactive Map
URL: https://rda.gov.lk/rda_project_new/map

The RDA map exposes Class A, Class B, Class E, district boundaries, offices, and an all-roads view. It is a reference for road hierarchy, not a replacement for the fixed illustrated artwork.

## OpenStreetMap Sri Lanka Project
URL: https://wiki.openstreetmap.org/wiki/Sri_Lanka

OpenStreetMap provides the open road and place data used for geographic cross-checking. The page links to the Sri Lanka map, quality checks, and local tagging guidance. It identifies Sri Lanka’s OSM project and contributors across places including Jaffna, Vavuniya, Colombo, Kandy, Galle, Matara, Nuwara Eliya, Ratnapura, and Batticaloa.

## Geofabrik Sri Lanka OSM Extract
URL: https://download.geofabrik.de/asia/sri-lanka.html

Geofabrik provides current Sri Lanka OSM extracts. At retrieval time the page stated that the PBF extract contained OSM data through 2026-08-31T20:21:20Z. The extract contains the full road network and is suitable for GIS/routing analysis; the page attributes the data to OpenStreetMap contributors under ODbL 1.0.

## Audit interpretation

Use the RDA Class AA/A corridors for solid main-road lines. Use B-class approaches, park entrances, mountain access roads, waterfall/heritage spurs, and scenic highland alternatives for dashed local/scenic lines. The illustrated atlas remains a visual base; its route overlay must follow only orange corridors already drawn in the artwork. Real-map geography validates the relationship and ordering of destinations, while manual image-space path tracing validates whether the corridor can be rendered on the artwork without crossing blank land.
